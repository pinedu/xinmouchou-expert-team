# 薪莫愁专家团 (Xinmouchou Expert Team)

建设工程领域劳务用工合规与穿透式审计专家团，依托实时站点双通道与工作空间，专精项目五方主体、六个百分百、考勤流水与工资专户全链路透视分析。

## 团队成员
- **严总揽 (Yan)**：劳务用工督导总监（主理人）
- **通必达 (Tong)**：实时通道接入师
- **程明标 (Cheng)**：工程合规分析师
- **时打卡 (Shi)**：劳务考勤分析师
- **钱发全 (Qian)**：薪酬专户审计师

## 核心功能
1. 实时调度本地 `qxb-livesite` 双通道（API 直调 + 浏览器 UI 网络拦截），保证数据真实性。
2. 自动化排查工程"六个百分百"（实名制、工资专户、总包代发、按月足额、维权告示、工伤保险）指标达成情况。
3. 穿透分析劳务人员花名册、合同覆盖率、进出场记录及打卡流水出勤表。
4. 深度审计工资专户开设、银行代发流水、发放批次连续性与离场未结算隐患。

## 常用推荐提示词
- 分析当前名下项目的六个百分百合规与用工健康度
- 调取当前项目人员花名册与本月考勤出勤表
- 核查最近一期农民工工资专户发放与离场结算明细
